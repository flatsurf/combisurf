``perm.h``: partial permutations in C
=====================================

The header ``combisurf/src/perm.h`` declares functions on partial
permutations of :math:`\{0, \ldots, n - 1\}`, given as arrays of ``n`` ints
with ``-1`` on the inactive points. They are implemented in
``combisurf/src/perm.c``.

The code is plain C99 and does not depend on Python, so that it can be
tested from standalone C programs and compiled into each Cython extension
that uses it. No function allocates memory: every buffer is handed in by the
caller, with the size given in its entry below.

The functions on a whole permutation come in two forms: ``_perm_func`` takes
the array and its length, and ``perm_func``, an inline wrapper, takes a
:c:type:`perm_t`. The functions on orbits, :c:func:`_perm_orbits_find` and
:c:func:`_perm_orbits_union`, act on a union-find array and have only the
first form.

.. c:macro:: PERM_INLINE

   The storage class of the functions defined in the header,
   ``static inline``.

Types
-----

.. c:struct:: perm_struct

   A partial permutation: the image ``p[h]`` of each point ``h`` of
   :math:`\{0, \ldots, n - 1\}`, ``-1`` when ``h`` is inactive.

   .. c:member:: int *p

      The images, an array of ``n`` ints.

   .. c:member:: int n

      The number of points.

.. c:type:: perm_struct perm_t[1]

   A :c:struct:`perm_struct` as an array of one element, so that a
   ``perm_t`` declared on the stack is passed by pointer.

Checks
------

.. c:function:: int _perm_check(const int *p, int n, int *seen)
.. c:function:: int perm_check(const perm_t p, int *seen)

   Check that ``p`` is a permutation of its active points.

   ``seen`` is a work buffer of ``n`` ints; its content on return is
   undefined.

   Return ``1`` when ``p`` is a permutation of its active points, ``0`` when
   it is injective and in range but sends an active point to an inactive
   one, and ``-1`` when an image is out of :math:`\{-1, 0, \ldots, n - 1\}`
   or two active points have the same image.

Cycles
------

.. c:function:: void _perm_id(int *res, int n)
.. c:function:: void perm_id(perm_t res)

   Set ``res`` (``n`` ints) to the identity: ``res[i] = i`` for every ``i``.

.. c:function:: int _perm_dense_cycles(int *id, int *size, const int *p, int n)
.. c:function:: int perm_dense_cycles(int *id, int *size, const perm_t p)

   Number the cycles of ``p`` by their smallest point, ``0, 1, 2, ...``.

   Write into ``id`` (``n`` ints) the index of the cycle of each active
   point, and into ``size`` (``n`` ints) the length of that cycle; both are
   ``-1`` on the inactive points. ``size`` may be ``NULL``, and is then not
   written.

   Return the number of cycles, or ``-1`` when the walk along a cycle leaves
   :math:`\{0, \ldots, n - 1\}` (an image ``-1`` or out of range on an active
   point); ``id`` and ``size`` are then partly written. A walk stops at a
   point already numbered, so that a non-injective ``p`` does not loop.

Orbits
------

The orbits of the group generated by the permutations merged so far are kept
in a union-find forest, given by the array ``parent`` of the points: the root
of a tree is its own parent, and the representative of an orbit is its
smallest point. ``parent`` starts as the identity (:c:func:`_perm_id`), every
point in an orbit of its own.

.. c:function:: int _perm_orbits_find(int *parent, int h)

   Return the representative of the orbit of ``h``, with path halving: every
   point met on the way gets its grandparent as its parent.

.. c:function:: void _perm_orbits_union(int *parent, int a, int b)

   Merge the orbits of ``a`` and ``b``: the larger of their representatives
   gets the smaller one as its parent, so that the representative of the
   merged orbit is again its smallest point.
