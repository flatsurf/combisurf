partial_sums#

Data structure for efficient consecutive partial sums

We consider a vector v of fixed size n on which we allow two operations - updates of the form v[i] += x - computation of the partial sum sum(v[i:j])

Taking a plain array for implementing the above leads to O(1) arithmetic cost for updates and O(n) for partial sums. This direct approach is in PartialSumsNaive. The PartialSumsBinarySplitting implement a data structure that do both updates and partial sums in O(log(n)) time.

combisurf.partial_sums.PartialSums#

alias of PartialSumsBinarySplitting

class combisurf.partial_sums.PartialSumsBinarySplitting(n)[source]#

Update and partial sums in O(log(n)).

Given n=2^b, we store the 2^{b+1} - 1 partial sums [a2^l, (a+1)2^l) for l in {0,1,ldots,b-1}. We store these partial sums on a plain list and the tree structure is implicit. The leaf [a,a+1) is stored at position 2^b a. The parent of i is i//2 (or i >> 1).
